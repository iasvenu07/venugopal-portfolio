# Venugopal Portfolio Website

Modern responsive personal portfolio website.

## Features

- Fully Responsive
- Dark UI Design
- Smooth Scrolling
- Typing Animation
- Interactive Hover Effects
- Professional Portfolio Layout
- Resume Download
- Project Showcase

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Tailwind CSS

## Setup

1. Download the project
2. Add images inside assets/images
3. Add resume PDF inside assets/resume
4. Open index.html
